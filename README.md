# Bank Management (Hibernate)

Desktop application for managing bank data: clients, accountants, contracts and credits.

## Features

- CRUD for banks, clients, accountants, contracts and credits
- Swing table view of database records
- ORM mapping with Hibernate / JPA

## Tech stack

Java, Hibernate, JPA, PostgreSQL, Swing, Maven

## Getting started

Create a PostgreSQL database, set the credentials in `src/main/resources/META-INF/persistence.xml`, then run `UserForm` from your IDE.
